# 22 - SpellBook (Lists)

A wizard spellbook manager built to practice C# List operations.

## Concepts Practiced
- Creating and initializing a List
- .Add() — learning new spells
- .Remove() — forgetting spells  
- .Count — tracking spellbook size
- .Contains() — checking for a specific spell
- Array.Exists() combined with List
- OrdinalIgnoreCase for case-insensitive input

## How to Run
Open in Visual Studio, set as startup project, run with F5.
